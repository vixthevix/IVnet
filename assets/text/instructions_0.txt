Before you begin, ensure you have:
   An available Network Interface Device (NID) 
   that is not your main WiFi device, 
   such as a WiFi dongle.
   
   Configured your country code 
   in the config menu.
   (look for your code at 
   wikipedia.org/wiki/ISO_3166-1_alpha-2)

1) On the main menu, click "START".

2) Select your NID 
   (if using a dongle, refresh while unplugged 
   and while plugged to recognize it).

3) Select a DNS server to connect to.

4) Wait for the device to be set up, 
   and if no errors occur, you are good to go!
